# AI Infra 完整学习与面试清单

这是当前岗位族的覆盖清单；目标 JD 确定后调整优先级，不承诺穷尽所有公司题型。配套文章见 [知乎原文资料索引](Resources/Zhihu/README.md)，原文分类与学习模块的关系见 [来源记录](Resources/ArticleMapping.md)。收录资料不改变本清单的验收状态。

## 如何验收

- P0：默认推理面试主线；P1：按岗位深化；P2：有余力或岗位明确要求时做。清单不是 12 周内必须全部做完的作业。
- 概念/推导项至少 L2：闭卷解释正确、写明假设，并通过一个新例子。实现/实验/诊断项至少 L3：独立完成且留正确性或场景证据。L4 还需跨日复测和变式通过。
- 完成时把 `[ ]` 改为 `[x]`，在该行末追加“日期 · 等级 · [证据](真实相对路径)”。有提示的完成只能记录辅助程度，不能冒充独立验收。
- 无 GPU 可先完成推导和 CPU 部分；明确要求 CUDA/NCCL/真实服务的项在实机验证前保留未勾选，记录在 [硬件债务](Learning/Progress.md)。
- 状态需要细分时在行尾注明“进行中 / 待硬件 / 待复测”；历史和具体回答存 Session。首次建立全部未勾选。

- [ ] **K15 · P1 · Tensor Core 与低精度**：说明 dtype、layout、对齐和累加精度要求；用实际设备条件限定结论。
- [ ] **K16 · P1 · CUDA Graph 与异步流水**：解释 launch overhead、捕获限制和传输/计算重叠，设计对照。
- [ ] **K17 · P2 · 编译器链路**：画图捕获 → IR → 融合/调度 → 代码生成路径，解释 graph break 与动态 shape。
- [ ] **K18 · P2 · 高级算子专题**：任选 MoE dispatch、attention backward 或量化 GEMM，交付正确性与性能报告。
