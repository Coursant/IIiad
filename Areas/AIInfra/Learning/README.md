# 学习记录与持续推进

每次只追踪真正发生的学习。入口：[目标](Profile.md)、[进度](Progress.md)、[第一周](FirstWeek.md)、[Session 索引](Sessions/README.md)。

## 每课 60–90 分钟

| 时间 | 动作 | 留下什么 |
|---|---|---|
| 0–10 分钟 | 到期复测或闭卷诊断 | 原始回答与提示次数 |
| 10–25 分钟 | 针对错误读一段资料 | 一张概念图/一个公式及来源 |
| 25–65 分钟 | 预测、实现或手算 | 代码/推导、命令、结果和差异 |
| 65–80 分钟 | 面试追问与变式 | 回答、评分、暴露的问题 |
| 80–90 分钟 | 更新记录 | Session、错题、复习日期、下一步 |

## 文件约定

- `Sessions/YYYY-MM-DD-SNNN-topic.md`：从 [Session 模板](../Templates/Session.md) 复制，课次编号递增；真实课次开始时创建。
- 知识笔记：对应知识模块中新建主题 `.md`；按 [Note 模板](../Templates/Note.md) 写机制、反例和来源。
- 实验：对应模块 `CaseStudy/<NN_topic>/` 内保存独立代码及 [实验报告](../Templates/Experiment.md)。
- 每周复盘：本目录中 `YYYY-MM-DD-WNN-review.md`，使用 [WeeklyReview](../Templates/WeeklyReview.md)。
- 模拟/真实面试：`Interview/Records/` 中按日期建立记录；初次记录时创建目录，使用 [Interview 模板](../Templates/Interview.md)。
- 历史原始输出太大时保留小型 CSV/JSON 摘要，并记录完整文件位置、版本和校验值。

## 收尾顺序

保存 Session → 达到门槛才勾选 CHECKLIST 并贴证据 → 更新 Progress 当前任务 → 将错误加入 Mistakes → 向 Reviews 填实际到期日 → 更新 Session 索引 → 根 DESIGN 追加变更记录。

复习建议在首次验收后的第 1、3、7、14 天进行；这是本计划的节奏约定，可按遗忘情况调整。复测失败降级并重新安排，不删除失败记录。

- “读取 AIInfra 进度，安排今天 60 分钟的任务；先让我回答，不直接给答案。”
- “按题号 I03 追问我，每次一问，最后保存原始回答和评分。”
- “检查这个实验的正确性、计时方式和结论，指出证据不足的部分。”
- “对我做一次 60 分钟推理服务模拟面试，结束后更新错题和复习队列。”

只有打开仓库并开展一次会话时才会执行这些动作；本区文档没有后台提醒或自动跟踪进程。
