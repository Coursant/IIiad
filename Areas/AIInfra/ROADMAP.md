# 12 周面试准备路线

默认每周 10 小时，推理服务优先；以实际开始日计 W1。信息待补时参照 [Profile](Learning/Profile.md)，先做 [Diagnostic](Interview/Diagnostic.md)。这是约 120 小时的首轮计划，清单中的全部高级项不在此周期内强制完成。

## 目标与时间预算

每周约 2 小时读文档/推导、5 小时实现与实验、2 小时闭卷面试/编码、1 小时复盘。平日四次各 1 小时，周末两次各 3 小时；可按实际安排等量调整。每周最多推进一个主项目里程碑。

首轮目标：完成一个可复现推理服务项目和一个算子/调度小实验；能讲清核心概念并手算资源；两次模拟面试达标。所有实机结论都要有实际数据，没有硬件时先保留验证债务。

| 周次 | 主目标 / 关键任务 ID | 当周可交付物 | 周末验收 |
|---|---|---|---|
| W1 | 定位与基础：J01–02、F07–09、I03 | Profile、测评日志、稳定 softmax、KV 手算 | 能解释单位、shape 和数值稳定性；选出三项薄弱点 |
| W2 | 模型与框架：F09–12、I01–04 | 小型训练循环/attention 参考、模型内存账本 | 闭卷画训练和推理路径；CPU 输出正确 |
| W3 | CUDA 基础：K01–06、K13 | vector add + Reduce 正确性与计时记录 | 解释索引、边界、同步；无 GPU 则只完成 CPU 参考与推导 |
| W4 | 算子与 profiling：K07、K09、K11、P02–06 | 选 softmax 或 GEMM 完成项目 P-A 的核心实验 | 给出一个有证据的瓶颈假设，解释收益或无收益原因 |
| W5 | 数据并行：D01–05、D13 | 小型 DDP 实验、global batch 与通信手算 | 解释 loss/梯度语义；标明 backend 和设备 |
| W6 | 并行取舍：D07、D09–10、D14 | ZeRO/TP/PP 显存通信对照、给定硬件方案 | 接受“显存不足/网络变慢”两个变式追问 |
| W7 | 推理服务基线：I05–06、I09–10 | 项目 P-B 固定版本、运行命令、原始基线 | 解释 KV 块管理和 batching；无硬件先做调度模拟 |
| W8 | 调度与优化：I07–08、I12–13、I22 | 两次单变量对照，保存吞吐/尾延迟/失败率 | 说清如何避免用质量下降或漏算排队换取虚假提升 |
| W9 | 源码与进阶：I11、从 I14–18 选一项 | 一张源码路径图 + 一个专题报告 | 将论文机制对应到固定版本代码，能说明差异 |
| W10 | 系统设计：S01–05、S11 | 容量计划、故障演练、项目一页纸 | 45 分钟设计服务，处理 OOM、超时与取消 |
| W11 | 面试与补缺：J03–09、J11 | 简历证据表、第一次模拟、三项主要错题修复 | 按 MockInterview 评分，不足处进入 W12 |
| W12 | 跨日复测与投递准备：J10–12 | 第二次模拟、复测记录、岗位匹配表 | 达到自测门槛则进入投递；不达标延长对应模块 |

算法/工程编码贯穿全程：每周至少一题限时独立完成并复述边界；忙周优先保留一次复测。不是把编码能力留到 W11 才学。

## 阶段门槛

- W2 后：能闭卷推导一个新配置的 KV 显存、解释 attention shape；否则回补 F07–12。
- W4 后：至少一个独立小实验有正确性证据；有 GPU 才能验收设备性能。不能只展示跑过教程。
- W6 后：能按“切什么、在哪通信、节省什么、代价是什么”比较 DDP/ZeRO/TP/PP。
- W10 后：主项目报告具备环境、基线、两个对照、质量/正确性、失败尝试与限制。
- W12 后：按 [模拟评分](Interview/MockInterview.md) 判断准备度；项目 GPU 证据缺失时明确岗位匹配缺口。

## 时间紧时的 4 周分支

适用前提：已有 C++/Python/Linux 与基本 PyTorch 能力；测评不满足时不要用压缩计划替代补基础。

| 周次 | 必须留下的结果 | 暂缓范围 |
|---|---|---|
| 1 | 测评、目标 JD、显存/通信估算、Transformer 与核心推理机制复述 | 高级编译器、复杂 MoE |
| 2 | 一个小模型服务基线与两次对照 | 多框架横向铺开 |
| 3 | 项目答辩、系统设计、算法/工程编码、第一次模拟 | 大规模训练平台建设 |
| 4 | 针对失分点复测、第二次模拟、简历证据核验 | 无关 P1/P2 |

每周复盘回答：产出了什么证据？哪项仍依赖提示？阻塞是基础、硬件还是时间？下周删减什么？没有完成时优先缩范围，不增加虚构的进度。
