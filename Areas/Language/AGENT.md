# AGENT.md — Language 共同笔记约定

本文件管理 `Areas/Language/` 下跨语言内容；单语言案例仍遵循各轨道的 `AGENT.md`。修改本区前同时阅读根 `AGENT.md` 与 `DESIGN.md`，改动后在 `DESIGN.md` 第 5 节追加记录。

## 共同内容放置规则

- 涉及两种及以上语言的同一概念、设计取舍或用法比较，放在 `Common/<Topic>.md`，不要分散复制到各语言轨道。
- 单语言的独立可运行练习放在相应轨道的 `CaseStudy/`；共同笔记可以链接这些练习，但不代替它们。
- 共同笔记先选一个足够具体的共同问题，给出相同的行为与验收条件，再按执行过程比较三种语言的关键语义、设计接口和边界条件；避免拆成零散术语清单。
- 变量与内存管理比较沿一个容器变量的完整生命周期展开，依次解释初始化、类型推导、存储/生命周期/作用域、ref/ptr、赋值与 copy/move/ref；追踪别名的后续有效性，并说明类型定义和语言默认规则各决定什么。
- 写明比较所依据的语言版本。C++ 内容以本仓库的 C++17 为准；遇到 C++20 之后的特性须单独标出。
- 关键语义和易混淆处附官方文档或标准草案链接。示例应能独立理解；可执行代码在本地验证后记录验证方式。
- `Dream.md` 是既有的个人速记，不由共同笔记规则自动改写；需要整理时可在新笔记中引用。
