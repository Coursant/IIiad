# 核心功能复刻路线

这是本学习项目的实施设计。上游参考目录见 [SOURCES.md](SOURCES.md)，每节课再核实具体符号与实现；下表不是上游代码结构的逐项断言。

用户选择想练习的语法后，优先映射到可推进的模块；跨阶段练习可以先完成接口或局部实现，记录待接入的依赖。

2026-09-30 起按用户选择，从 [S001 核心类设计](S001_core_class_design.md) 切入 M3，用最小 Tick 值支撑策略接口练习，再回补 M1/M2；阶段编号表示功能范围，不强制学习顺序。

| 阶段 | 本地模块与练习方向 | 验收条件 | 状态 |
|---|---|---|---|
| M0 | 工程入口、CMake | 独立构建并运行，说明当前功能边界 | 已完成 |
| M1 | Tick、Bar、合约、订单和成交类型；struct、enum class、构造、const/ref | 构造并校验数据，明确字段单位、时间和价格精度 | 未开始 |
| M2 | 离线行情读取、缓存和订阅分发；容器、迭代器、lambda、回调 | 固定数据按时序分发，正确处理空输入、格式错误和重复订阅 | 未开始 |
| M3 | 策略接口、上下文和生命周期；虚函数、override、RAII、智能指针 | 一个策略完成初始化、接收行情和停止；上下文可查询已到达的数据；无悬空引用 | 进行中：S001 设计教学，待用户实现 |
| M4 | 策略信号、目标仓位到订单；封装、组合、算法 | 目标仓位减当前仓位得到所需交易量；重复目标不会重复下单；在途订单有处理规则 | 未开始 |
| M5 | 模拟交易通道、订单状态机与风控；接口、状态、错误处理 | 可下单、拒单、成交、撤单；状态迁移合法；记录成交规则；验证超限拒绝与重复回报 | 未开始 |
| M6 | 持仓、现金、费用和盈亏；值语义、资源管理 | 已知买卖序列的持仓、现金、手续费和盈亏可手算核对，重复成交回报不重复记账 | 未开始 |
| M7 | 回测调度、配置、日志、结果落盘；文件 I/O、异常、模块组织 | 一条命令跑通完整闭环并输出订单、成交、权益及摘要；相同数据和配置产生相同结果 | 未开始 |

核心闭环的最终验收：一个完整示例策略在固定离线数据上完成至少一次买入与卖出；风控有通过和拒绝场景；时序与成交假设明确；结果可复现且资金变化可核对；README 给出运行命令；各模块能追溯到上游参考及本地改写说明。

进一步扩展可包括多策略目标合并、多品种、行情持久化、异步队列、线程同步、策略工厂与动态加载，以及其他引擎或交易适配器。每次根据用户兴趣增加具体验收项；它们目前不计入 M1–M7 的完成率。上游特有接口兼容、全部引擎、真实柜台连接和性能指标均未实现，也未验证。
